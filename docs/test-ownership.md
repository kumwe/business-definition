test:ownership` verifies the complete API, real PHPUnit inventory, conformance corpus paths, architecture gate and
explicit App transfer records; its nine negative fixtures reject missing or fabricated coverage records. The map is
reviewed by responsibility, not a substitute for execution.

The package owns immutable constructors, field and relationship matrices, typed ASTs, graph/cycle and complexity
refusal, hostile input, canonical bytes/digests, ordered compatibility, registries, exact dependency composition, DI
failure and archive/public API boundaries. Engine consumes the language-neutral formula corpus and owns native
execution/sanitizer/fuzz/performance parity.
